# Features

MyGo!!!!! Asia Tour promo page — **required behavior** is captured in **Components** (each with a checkmark and how it works). Anything after that is **Decoration**: optional **unique visual / motion art** only—not needed for the site to “work.” We list decorations **aside** here as we add them.

## Components

- [x] **Responsive navigation bar (`#row-nav`)** — Sticky header **`site-header-nav`** + **`site-navbar`** ( **`navbar-dark`** kept for toggler contrast). **Decoration:** main **`#2F4858`**, accent **`#33658A`**, white nav text, **Russo One** at larger sizes — see **`css/styles.css`**, **`index.html`** font links, and **Decoration → Site chrome tokens + navbar**. Official MyGO!!!!! logo (`image/MyGO_Logo.png`) links to **`#row-hero`**. Links: Asia Tour 2026, Members Spotlight, Secure Your Dream Ticket. **Ignite the Beat** (`#navIgniteBeat` → **`#js-nav-song-list`**) is filled by **`initSongsPreview()`** from **`data/songs.json`**: each **`dropdown-item`** shares **`data-song-index`** with **`#preview-song-list`** and **`applyWorkSelection()`**; divider + **Open preview player** → **`#row-preview`**.

- [x] **Hero key visual (`#row-hero`)** — **Final:** Full-width `col-12` hero shows `image/key_visual.webp` (**1000×400** px, wide banner). The wrapper uses **`aspect-ratio: 1000 / 400`**, so hero height tracks viewport width (no fixed **vh** that fought the new art). The `<img>` is absolutely positioned and **`object-fit: fill`** inside that box (same aspect as the file → no skew). **`width` / `height`** on the tag match the file for layout stability. Black fallback behind the block; overlays/interactions can be added later.

- [x] **Footer (`site-footer`)** — **`site-footer-themed`**: main-blue **gradient** shell, **accent** top border, soft **upward shadow**; **`.border-top`** rows use translucent white dividers. **`.link-light`** social icons: hover **lift** + **cyan glow** (**`prefers-reduced-motion`**: no transform). **`mt-auto`**; **`.site-footer-content`**: centered icon nav (**`twitter-x`**, **`facebook`**, **`instagram`**, **`tiktok`**), fictional / © copy, **simulation** row — **`aria-label`** on links.

- [x] **Asia tour map (`#tour-map`)** — Leaflet with OpenStreetMap tiles, five stops in order (Tokyo → Singapore) with shared **Bootstrap Icon** `bi-star-fill` **`divIcon`** markers, **`fitBounds`** over Asia. Stops live in **`TOUR_MAP_STOPS`**; **`initTourMap()`** stores **`tourMapMarkers`** for table sync. While a table row highlights a stop, the matching marker’s **`.map-star-marker-inner`** gets **`.map-star-marker-inner--highlight`** (CSS: larger star + warm glow). **Layout:** **`#row-tour`** grid row uses **`align-items-stretch`**; **`tour-map-col`** / **`tour-table-col`** are **`d-flex flex-column`**; map has **`flex-grow-1`** and from **`md`** up **`height: 100%`** so it can match a taller table column (**`400px`** height when stacked). **Decoration:** **`#tour-map.tour-map`** — **`4px`** solid **`var(--site-color-main)`**, **`border-radius`**, **`overflow: hidden`**, soft shadow tinted to the main hue. **Route legs:** after **`data/concerts.json`** loads, **`addTourRoutePolylines()`** draws dashed **SVG** segments between consecutive stops (loaded asynchronously after markers). Segment **i → i+1** uses **`isConcertRegistrationClosed(concerts[i])`** (same rule as registration): if that show has started, the leg is **`.tour-route-line--animated`** (light blue, glow, **`stroke-dashoffset`** loop); otherwise **`.tour-route-line--static`** (dark gray, no animation). Leaflet **`markerPane`** sits above vector lines so stars stay visible. JSON failure draws all legs static.

- [x] **Tour dates table (`#tour-dates-tbody`)** — Table **`tour-dates-table`**: type **`1.0625rem`** (**`th`** **`1.1rem`**); **`thead`** cells **centered**, **accent** (**`var(--site-color-accent)`**) header bar with white type; **tbody** alternates **light gray** / **light gray-blue** (**`nth-child`**, skipping **`tour-dates-status`** / **`tour-dates-loading`** rows). **Hover:** mix toward accent, **inset** accent bar, soft shadow (**`prefers-reduced-motion`**: no transition). **Active** map-linked row keeps warning strip + tint; hover stacks a shadow. **Border:** **`2px`** **`var(--site-color-main)`**, rounded frame. **`table-responsive`** in **`tour-table-col`** is a flex column with **`flex-grow-1`**. Rows built by **`initConcertsTable()`**: **`$.getJSON('data/concerts.json')`** then append `<tr>` cells for date/time, city, venue. Each concert uses **`startsAt`** as **ISO 8601 with UTC offset** plus **`timeZone`** (IANA); **`formatConcertDateTime`** uses **`Intl.DateTimeFormat`** (`en-US`, **`dateStyle: full`**, **`timeStyle: short`**) so shown times are correct **local civil time** for that city. Empty / error / loading rows use **`tour-dates-status`** (and loading also **`tour-dates-loading`**). Rows whose **`location`** matches **`TOUR_MAP_STOPS`** get **`data-tour-stop-index`**, class **`tour-date-row`**, and **`cursor: pointer`**. **`bindTourDatesToMapMarkers()`** (after a successful load): **`mouseenter` / `mouseleave`** set **`tourTableHoverStopIndex`** and call **`syncTourMarkersTableHighlight()`**; **`click`** toggles **`tourTableStickyStopIndex`** and **`tour-date-row--active`** on the row (second click same row clears sticky). Unknown cities omit **`data-tour-stop-index`** (no map link).

- [x] **Concert registration window (local time)** — Separate from the generic lottery UI: **`#reg-concert`** in **`#lottery-register-form`** lists every show from **`data/concerts.json`**. Each **`<option>`** label is **`location`** + **“ — ”** + **`formatConcertDateTime()`** (same local-time display as the tour table). **`isConcertRegistrationClosed()`** treats the show as closed when **`Date.now() >= new Date(concert.startsAt)`** (the **`startsAt`** string encodes a single instant, including offset). Closed rows append **` -- ended`**, stay visible, and use **`disabled`** so they cannot be chosen. **`initLotteryRegistration()`** fills the select on **`$.getJSON`** success, caches **`registrationConcertsList`**, and on **`submit`** rejects a closed or invalid index ( **`is-invalid`** on the select). Empty list or fetch failure leaves one disabled status option. **Debug data:** Tokyo uses **`startsAt`** on **2026-05-01** so that show reads as ended soon after that instant.

- [x] **Members (`#row-members` / `#members-root`)** — Section **`members-spotlight`** and its **`.container`** use **transparent** backgrounds so **`page-bg-decoration`** (**`image/background.webp`**, blurred) shows through; character cards keep their own fills. Heading **`spotlight-section-heading`** (shared with **Ignite the Beat** / **Lottery registration**): **Russo One** (**`var(--site-nav-font)`**), main blue text, **`clamp(2rem, …, 3rem)`** (~**48px** cap), accent gradient rule **`::after`** with soft glow. **`data/characters.json`** lists each character with **`name`**, **`position`**, **`img_front`**, **`img_end`**, **`color`** (paths paired to image files under **`image/`**). **`initMembersSection()`** sets **`--character-accent`** via **`sanitizeHexColor()`** per card (**`.character-card--themed`**): **4px** border uses that hue, plus **layered `box-shadow` drop shadows** and a **`color-mix`** glow where supported. Flip photo area uses **taller `aspect-ratio: 9 / 16`**, **`min-height: clamp(...)`**, **`object-fit: contain`**, and a tinted face background so **full body art** shows without **`cover`** cropping. **3D flip** unchanged (**hover** / **tap** / **keyboard**).

- [x] **Works preview (`#row-preview`)** — **`works-preview-section`**: section title **`spotlight-section-heading`** (same style as **Members Spotlight** / **Lottery registration**). MV + try-out **always one row**: **`col-6`** columns (**`align-items-stretch`**), **`works-preview-mv-col`** / **`works-tryout-col`** flex columns; try-out **`works-tryout-panel`** **`flex-grow-1`** with song list **`flex-grow-1`** and audio **`mt-auto`** so the panel fills height beside the **16×9** MV. **Decoration:** **`works-preview-mv-label`**, **`works-preview-mv-wrap`**, **`works-tryout-panel`**, **`works-tryout-heading`**, **`works-preview-song-list`** / **`works-preview-track-btn`**: try-out copy scaled **×1.6** (**`calc(... * 1.6)`** on heading, list rows, and track buttons; **`padding-block`** on buttons scaled too). **`data/songs.json`**, **`initSongsPreview()`**, **`applyWorkSelection()`**, nav dropdown, **`#works-float-control`**, **`syncSongPauseOverlay()`** unchanged in behavior.

- [x] **Lottery registration (`#row-register`)** — **`register-section`**: tinted **gradient** + **accent** top rule. Title **`spotlight-section-heading`**. **Stadium column:** **`register-subheading`** / **`register-intro`** (**Russo One** + main for title); **`.stadium-ring`** inside **`#row-register`** recolored to **main / accent** ladder; **S** center **white** on **accent** gradient. **Form column:** **`register-card`** (**main** border, soft fill), **`register-card-title`** (**Russo One**), **labels** main blue, **focus** rings **accent**, **`reg-payment-btn`** main outline → **accent** fill when **hover** / **`active`**, **`register-submit-btn`** **accent** solid. **Concert** **`#reg-concert`**, **tier**, **tickets**, **payment** + **`initLotteryRegistration()`** behavior unchanged (**rick-roll** new tab). Simulation copy in **footer** only.

## Decoration (visual art only)

Optional effects listed **aside** from core components. Each line is a distinct look / feel / motion experiment—not required functionality.

- **Fixed blurred backdrop** — **`page-bg-decoration`** (first child of **`body`**) paints **`image/background.webp`** as **`background-attachment: fixed`** + **`cover`**, with **`opacity: ~0.4`**, **`filter: blur(12px)`**, and slight **`scale(1.08)`** so edges stay soft. **`pointer-events: none`**. **`body > main`**, **`footer`**, **`#works-float-control`**: **`position: relative; z-index: 1`**; **`#row-nav`**: **`z-index: 2`** only so **`sticky-top`** is not overridden. **`prefers-reduced-motion`**: lighter blur, no scale.

- **Site chrome tokens + navbar** — **`:root`** defines **`--site-color-main`** (**`#2F4858`**), **`--site-color-accent`** (**`#33658A`**), **`--site-nav-text`** (**white**), **`--site-nav-font`** (**Russo One** + system stack). Google Fonts loads **Russo One** in **`index.html`**. **`#row-nav.site-header-nav`**: main fill, accent-tinted bottom border, soft drop shadow. **`.site-navbar`**: larger type (**`1.125rem`**, **`1.3rem`** from **`lg`** up); **`.navbar-collapse`** has **`flex-grow-1`** (Bootstrap) so it fills space beside the logo; **`.navbar-nav`** uses **`ms-auto`** to pin links to the container’s right; small-screen **`text-align: right`** / **`align-items: flex-end`** for the open menu; transparent bar; **`.nav-link`** white, accent hover / open ( **`color-mix`** + **`@supports`** fallback), inset accent bar on hover; **`.dropdown-menu`** dark teal panel, white items, accent hover/active; divider + **`.dropdown-item-text`** tuned for legibility; toggler border + focus ring uses accent.
